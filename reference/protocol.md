# 论证结构：小分子自组装机理研究

这份文档写的是**科学论证结构**，不是操作手册。命令见 `SKILL.md`，
判据的自动检查见 `scripts/study_report.py`。

> 本文件用一类常见课题作范例：染料分子在水中自发组装成 J-聚集体，
> 聚集导致荧光猝灭、激发能转为非辐射衰变，服务于光热治疗/光声成像。
> **第二节的量的定义、第三节的比较五关、第五节的坑，对任何小分子自组装研究都适用。**
> 第一节的 a–e 分工是"发色团 + 光物理"这类课题的写法，换课题按同样格式重写即可。
>
> 非芳香体系（胶束、纤维、共组装）不需要第一节和"滑移角/层间距"那套，
> 直接用 `aggregate.py` 的聚集尺寸、形状、组成、径向密度即可，判据见第二节。

## 零、先分清你的体系需要哪一层分析

| 体系 | 用哪层 | 主要观测量 |
|---|---|---|
| 芳香分子堆叠（J/H 聚集） | 通用层 + 堆叠几何层 | 滑移角、层间距，另加聚集尺寸 |
| 胶束 / 囊泡 | 通用层 | 聚集数、Rg、径向密度（核壳） |
| 纤维 / 凝胶 | 通用层 | Rg、各向异性、长度方向的增长 |
| 多组分共组装 | 通用层 | 组成随时间的漂移 |
| 无机 / 杂化聚集体 | 通用层 | 尺寸、形状、组成 |

通用层 = `aggregate.py`，堆叠几何层 = `analyze.py`（可选）。

## 一、整条论证链

典型实验事实：分子形成 J-聚集体后荧光猝灭、ISC 被抑制，两条辐射通道都关掉，
激发能只能走非辐射途径产热——这正是光热治疗（PTT）和光声成像想要的性质。

理论计算通常要把这个现象拆成五个可算的环节：

| | 交什么 | 手段 | 谁的责任 |
|---|---|---|---|
| a | 前线轨道能隙；S0/S1 的给体-受体扭曲角 | TD-DFT | 电子结构 |
| b | 分子静电势 ESP | DFT | 电子结构 |
| c | 重组能 λ、振子强度 f | TD-DFT | 电子结构 |
| **d** | **滑移式堆积是否存在；相邻分子间距** | **全原子 MD** | **这个 skill** |
| e | 二聚体空穴-电子分离、CT 特征、IGM 作用类型 | Multiwfn + VMD | 电子结构 |

**MD 的作用是搭桥。** a/b/c 描述单分子，e 描述二聚体的电子结构，中间必须有人证明
"在液态水里这些分子真的会自发堆成滑移堆积、而且堆成什么样的几何"。
没有 d，e 里的二聚体就是硬凑的，审稿人会问"这个构型哪来的"。

## 二、MD 必须产出的量，和合格线

| 量 | 定义 | 合格线 | 说明 |
|---|---|---|---|
| J 型占比 | 滑移角 > 阈值（默认 32°）的分子对比例 | **> 50%** | 证明"滑移式堆积"是主导，不是偶发 |
| 层间距 d | 同一基团堆叠对、横向与中心距受限时的垂直分量 | 中位数 **≤ 4.0 Å** | 这才是能跟文献 3.4 Å 比的数量 |
| 相邻分子中心距 | 逐分子到最近邻居的中心距离 | 报告值 | 直接回答"相邻两个分子之间的距离" |
| RDF 第一峰 | 参考原子对或环质心 | 报告峰位 | 与层间距互为独立校验 |
| 聚集状态 | 簇尺寸随时间的趋势 | **稳定** | 还在"增长"说明没平衡，不能拿去比大小 |

**用错量会得出反向结论。** 法向量夹角对 J 型和 H 型都接近 0，分不开；
"垂直分量小"也不等于堆叠——同一层里并排的两个分子垂直分量同样接近 0。
必须同时约束中心距和横向偏移。

## 三、要写"X 比 Y 聚集得更厉害"之前，先过这五关

1. **浓度一致**（相对偏差 < 5%）。Packmol 的 `inside box` 只是摆放范围，输出的
   CRYST1 是坐标外接框，分子一大一小浓度就能差出一大截。这条不过，尺寸结论就是浓度结论。
2. **帧间隔和时长一致**。粗采样与细采样混用，按帧平均会让粗采样段权重缩水。
3. **力场旋钮一致**：`oneFourScaling`、`cutoff`、`timestep` 在各体系的生产段必须相同。
4. **分析口径一致**：同样的 cutoff、同样的层间距判据、同样的滑移阈值。
5. **采样足够**：簇尺寸趋势稳定，不是"这一帧刚好长大了"。

任何一条不过，`study_report.py` 都会把"取代基比较"判为 BLOCKED。

## 四、这类项目最常见的四个坑

1. **Packmol 盒子导致浓度漂移。** `inside box` 只限摆放范围，输出 CRYST1 是外接框，
   再经 VMD 外扩，各体系浓度可以差出 1.5 倍以上。
   修法：`scaffold.py --packmol --target-conc-mM <值>`，用 `-minmax` 把最终盒子钉死。

2. **力场旋钮在阶段之间不一致。** 典型是平衡用 1.0、生产写成别的值（手抄 conf 时最容易发生）。
   量级未必大，但方法学上必须修或交代。用日志里 `1-4 ELECTROSTATICS SCALED BY` 核对。

3. **坐标系 bug。** 分子解缠绕时若以自身第一个原子为原点，每个分子就有各自的坐标系，
   分子间距离全部作废。**体检线：最近邻距离不得小于 2 Å。**

4. **簇判据会渗透。** 接触判据下，一条首尾相连的链就足以让全部分子"连成一体"。
   报告前必须写明判据（接触/质心、cutoff），并看 `clusters_timeseries.csv` 的趋势。

## 五、MD 的结论怎么接回电子结构

- **二聚体模型的几何来源**：从平衡段取一帧，挑出堆叠最典型的一对
  （滑移角接近体系中位数、层间距 ≤ 4 Å），导出给 Multiwfn 算 e。
  这样 e 的几何是 MD 给的，不是从晶体里抠的。
- **ESP 假设的检验**：b 预测"静电排斥更小 → 堆得更近"。MD 能检验的只有"堆得更近"这一环，
  所以层间距必须在**同浓度**下比较，否则检验的不是 ESP。
- **能隙/重组能的变化**必须建立在真实堆积构型上，才能解释红移量级。

## 六、什么算"MD 这一环完成了"

- [ ] 各体系同浓度、同时长、同帧间隔、同力场旋钮
- [ ] 每个体系 J 型占比 > 50%，中位层间距 ≤ 4 Å
- [ ] 聚集趋势稳定
- [ ] 相邻分子间距有明确的数值和定义
- [ ] 二聚体几何已导出，供 e 使用
